📚 Student Record Management System
A simple Java console-based Student Record Management System that allows administrators to add, update, and view student records efficiently.

🚀 Features
Add new student records (name, ID, age, grade)

Update existing student information

View student details by student ID

Error handling for invalid inputs and missing students

Menu-driven administrator interface

Simple structure using static methods and variables

🛠️ How to Run
Clone or download the repository.

Open your terminal (Command Prompt or Git Bash).

Navigate to the project folder.

Compile the Java program:

bash
Copy code
javac StudentRecordManagementSystem.java
Run the program:

bash
Copy code
java StudentRecordManagementSystem
Follow the on-screen menu to manage student records!

📄 Requirements
Java JDK installed (Java 8 or higher recommended)

Basic command line/terminal access

📋 Program Structure
Student Data Storage: Parallel arrays (studentNames, studentIDs, studentAges, studentGrades)

Student Management: Handled by static methods inside the StudentRecordManagementSystem class

Administrator Interface: Console-based menu system

Error Handling: Input validation and ID search handling
